# Numetry_Task19_Librarydb

Library Management System (LMS) Database

Overview
The NumetryLibrary database is designed to manage books, authors, members, and book borrowing activities efficiently.

Database Schema
Authors Table - Stores author details like name and country.
Books Table - Stores book details, including title, author, genre, publication year, and available copies.
Members Table - Stores member details such as name, email, phone, and membership date.
BorrowedBooks Table - Tracks book borrow and return transactions.

Key Operations
Add a New Book: Inserts a new book record.
Issue a Book: Checks availability, issues the book, and updates copies.
Return a Book: Updates the return date and restores available copies.
This system ensures efficient book management and borrowing operations.
